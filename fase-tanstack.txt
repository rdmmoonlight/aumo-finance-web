Siap bro, gue bikinin fase paling santai biar gak langsung jebol. Intinya kita bikin `npm run dev` di port 3000 sehat dulu cuma 1 halaman, baru pindahin semua Page lama lu.

Ikutin urutan ini jangan lompat.

### FASE 0 - Backup dulu
```bash
cd frontend
git add. && git commit -m "backup before start"
```

### FASE 1 - Install TanStack Start
Hapus config lama yang bentrok, install yang baru.

```bash
npm install @tanstack/react-router @tanstack/react-start @tanstack/react-router-devtools
npm install -D @tanstack/router-plugin vinxi @vinxi/react vite-tsconfig-paths @vitejs/plugin-react
```

### FASE 2 - Bikin config sehat
Hapus `vite.config.ts` lama lu, ganti jadi 2 file ini di root `frontend/` (sejajar sama `package.json`):

**1. `app.config.ts` - ini otak nya Start**
```ts
import { defineConfig } from '@tanstack/react-start/config'
import { TanStackRouterVite } from '@tanstack/router-plugin/vite'
import tsConfigPaths from 'vite-tsconfig-paths'
import react from '@vitejs/plugin-react'

export default defineConfig({
  vite: {
    plugins: [
      tsConfigPaths(),
      TanStackRouterVite({
        target: 'react',
        autoCodeSplitting: true,
      }),
      react(),
    ],
  },
  server: {
    preset: 'node-server',
    port: 3000,
  }
})
```

**2. Update `package.json` scripts nya:**
```json
"scripts": {
  "dev": "vinxi dev --port 3000",
  "build": "vinxi build",
  "start": "vinxi start --port 3000"
}
```

**3. Update `tsconfig.json` pastiin ada ini:**
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./src/*"] },
    "moduleResolution": "bundler"
  }
}
```

### FASE 3 - Bersihin entry point lama
```bash
rm src/main.tsx
rm index.html
rm -rf src/pages
```
`main.tsx` sama `index.html` udah gak dipake di Start. Jangan panik.

Bikin file baru `src/router.tsx`:
```ts
import { createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'

export function getRouter() {
  const router = createRouter({
    routeTree,
    defaultPreload: 'intent',
    scrollRestoration: true,
  })
  return router
}
```
`routeTree.gen.ts` nanti ke-generate otomatis.

### FASE 4 - Bikin ROOT biar dev bisa jalan di 3000

Ini file paling penting. Bikin `src/routes/__root.tsx`:

```tsx
import { createRootRoute, Outlet } from '@tanstack/react-router'
import { HeadContent, Scripts } from '@tanstack/react-start'
import { QueryClientProvider } from '@tanstack/react-query'
import { queryClient } from '@/lib/queryClient'
import { AppLayout } from '@/components/layout/AppLayout'
import '@/styles/index.css'

export const Route = createRootRoute({
  component: RootComponent,
})

function RootComponent() {
  return (
    <RootDocument>
      <QueryClientProvider client={queryClient}>
        <AppLayout>
          <Outlet />
        </AppLayout>
      </QueryClientProvider>
    </RootDocument>
  )
}

function RootDocument({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <HeadContent />
      </head>
      <body>
        {children}
        <Scripts />
      </body>
    </html>
  )
}
```

Bikin `src/lib/queryClient.ts` kalo belum ada:
```ts
import { QueryClient } from '@tanstack/react-query'
export const queryClient = new QueryClient({
  defaultOptions: {
    queries: { staleTime: 1000 * 60 * 5, retry: 1, refetchOnWindowFocus: false }
  }
})
```

Bikin 1 halaman tes dulu `src/routes/index.tsx`:
```tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: () => <div className="p-10 text-2xl font-bold">AUMO SEHAT BRO 🔥 - TanStack Start jalan di 3000</div>
})
```

### FASE 5 - TES SEHAT DULU
```bash
npm run dev
```

Kalo lu liat di terminal:
```
[vinxi] ➜ Local: http://localhost:3000/
```
Buka browser. Harusnya tulisan AUMO SEHAT muncul. Kalo udah, lu udah 80% jadi.

Kalo error `routeTree.gen.ts not found`, jalanin dev 2x aja, file itu auto generate.

### FASE 6 - Baru pindahin semua page lama lu

Sekarang tinggal convert. Gak usah copy logic dulu, bikin shell nya aja:

```
src/routes/
├── __root.tsx
├── index.tsx // HomePage.tsx lama
├── dashboard.tsx // DashboardPage.tsx lama
├── chart-of-accounts.tsx // ChartOfAccountsPage.tsx lama
├── journal.tsx
├── guardians.tsx
└── reports/
    └── trial-balance.tsx
```

Contoh `src/routes/dashboard.tsx`:
```tsx
import { createFileRoute } from '@tanstack/react-router'
import DashboardPage from '@/pages/DashboardPage' // kalo masih ada backup nya

// ATAU langsung pindahin logic DashboardPage kesini

export const Route = createFileRoute('/dashboard')({
  component: DashboardPage,
})
```

Lakuin buat semua file di `pages/` lu. File-based routing: `/` = `index.tsx`, `/dashboard` = `dashboard.tsx`, `/reports/trial-balance` = `reports/trial-balance.tsx`.

Abis itu baru hapus folder backup `src/pages`.

Udah beres, `npm run dev` lu sekarang udah full Start + Query + shadcn ui lu yang lama tetep kepake.
