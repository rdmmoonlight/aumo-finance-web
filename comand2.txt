keterangan:
git clone	Membuka cabang baru
git commit	Membuat jurnal catatan (kunci perubahan)
git pull	Menarik update dari pusat
git push	Menyetor laporan ke pusat
git push -f	Memaksa pusat sama dengan lokal


lokal sbg folder utama:
git rebase --abort
git checkout main
git add .
git commit -m "Gunakan versi lokal sepenuhnya dan timpa versi remote"
git push origin main --force

commit preview:
git checkout main
git rebase --abort
git add .
git commit -m "Bismillah, fix atau update"
git push origin main --force

deploy APK:
git checkout main
git rebase --abort
git add .
git commit -m "Bismillah, fix atau update android"
git push origin main --force

commit production:
git checkout production
git add .
git commit -m "Alhamdulillah, release"
git push origin production --force

kalo error:
git pull origin main --rebase
git push
